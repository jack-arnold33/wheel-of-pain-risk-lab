# Wheel of Pain Risk Lab

A disposable PWA test application for validating platform assumptions before
implementation of
[Wheel of Pain Timer](https://github.com/jack-arnold33/wheel-of-pain-timer).

The lab uses a production-representative candidate PWA stack to assess risk.
That choice does not select the main application's architecture, and the lab
remains disposable.
